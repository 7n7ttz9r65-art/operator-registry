Welcome — 2-minute tutorial

1. What this is. A falsification registry for proposed Hilbert-Pólya operator candidates — mathematical constructions tested against fixed rules. Each candidate either passes, survives conditionally, or gets a no-go (REJECTED).
2. Reading a candidate. Every candidate is scored on 7 properties (trace, positivity, covariance, self-adjoint, compact resolvent, Weyl law, determinant). Each status is paired with a certification level: floating-point evidence is suggestive only; "proved"/"failed" require interval arithmetic or analytic proof.
3. Verdicts. REJECTED = a rule fired (no-go). CONDITIONAL_SURVIVOR = survives if named premises are proven. UNCERTIFIED_INDETERMINATE = not enough certified evidence to judge (e.g. floating-point-only negative). SCHEMA_VIOLATION = malformed record.
4. Run the audit. Dashboard → "Run Audit" runs every candidate through the rule engine and shows the verdict table. History is kept under "Runs & Saved".
5. Share & export. "Download registry (JSON)" exports everything; "Copy summary" copies a plain-text report. You can also add candidates and paste JSON imports.
